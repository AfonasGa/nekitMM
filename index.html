Моды для Meltiew с nekitMM

Мод — это папка с Luau-скриптом, иконкой и (по желанию) ресурс-паком. Моды работают прямо в приложении: в меню и в игре, в безопасной песочнице. Сервер Meltiew о них не знает.

Быстрый старт: открой в приложении Моды → Создать пример мода, включи его — и у тебя на экране появится кнопка. Весь код примера можно читать и менять.

Установка

  • Моды лежат в %APPDATA%\Godot\app_userdata\Meltiew\mods\<id>\ — кнопка «Открыть папку модов» открывает её на ПК.
  • Кнопка «Импортировать мод» ставит мод из .zip или одиночного .luau (работает и на телефоне).
  • Готовые моды — во вкладке «Каталог»: добавь репозиторий user/repo и жми «Установить».

Структура мода

my-mod/
  index.json     манифест и права (обязателен)
  main.luau      код мода (обязателен)
  index.png      иконка, до 512×512 (необязательна, большая ужмётся сама)
  pack.json      ресурс-пак (необязателен)
  assets/        звуки и картинки мода
  workspace/     личная папка мода: читать и писать может только он
{
  "name": "Мой мод",
  "description": "Что он делает",
  "version": "1.0.0",
  "UiManipulation": false,
  "Internet": false,
  "AdvancedFeatures": false,
  "api": 1
}

api — версия API модов, сейчас всегда 1. В манифесте можно описать "settings" — страницу настроек мода приложение нарисует само:

"settings": [
  { "key": "autoload", "type": "toggle", "title": "Работать при запуске", "default": false },
  { "key": "volume",   "type": "slider", "min": 0, "max": 1, "step": 0.1, "default": 0.5 },
  { "key": "style",    "type": "choice", "options": ["мило", "дерзко"] }
]

Права

ФлагЧто даёт
UiManipulationMeltiew.coreui — скрывать и проявлять элементы встроенного HUD: чат, полоски HP и стамины, хотбар, прицел, статистику
InternetMeltiew.http.get/post — запросы на http/https. Ответ ≤ 5 МБ, таймаут 10 с, localhost и приватные адреса запрещены
AdvancedFeaturesMeltiew.engine — твики движка: vsync, лимит FPS, масштаб 3D-рендера, MSAA. При включении показывается предупреждение

API модов

Моду доступен глобал Meltiew и Luau-стдлиба (math, string, table, task...). print() пишет в лог мода — он виден на странице «Моды».

События

Meltiew.on(name, fn) — подписка: chat {id,name,text} · join/leave {id,name} · dead {id} · place {id,name} · key {key,down} · settings

Уведомления

Meltiew.notify(text) — тост
Meltiew.big(text, secs) — крупное сообщение по центру (в игре)

Свой UI

local btn = Meltiew.ui.create("button", {x=24, y=160, w=160, h=52, text="Привет!"})
btn.on("pressed", function() end)
btn.set({text = "Изменён"})
btn.destroy()
  • Классы: panel, label, button, image, progress.
  • Свойства: x, y, w, h, text, text_size, text_color, color, image, value (0..1), visible, opacity.
  • Клики ловит только button и только в своём прямоугольнике — приложение под модом всегда кликабельно.

Файлы workspace

Meltiew.files.read/write/read_b64/write_b64/list/exists/delete — всегда асинхронно: Meltiew.files.read("a.txt", function(res) end) → res.ok, res.text. Только внутри своей workspace, ≤ 5 МБ на файл, ≤ 50 МБ на мод

Интернет

Meltiew.http.get("https://api.example.com/thing", function(res)
  if res.ok then
    local data = Meltiew.json.decode(res.text)
  end
end)
res.ok, res.status, res.text, res.b64. Требует флаг Internet

Встроенный HUD

Meltiew.coreui.list() / set(name, props) — имена: chat, health, stamina, hotbar, inventory, crosshair, stats, big_message, camera_button; свойства: visible, opacity. Требует флаг UiManipulation
Meltiew.coreui.add(container, class, props) — встроить свой элемент в игровое меню: вкладки menu_settings, menu_players, menu_help, menu_console, menu_mods. Возвращает handle как ui.create; элементы переживают смену вкладок

Прочее

Meltiew.info / settings / json.decode / json.encode
Meltiew.play_emote("wave") — эмоция от лица игрока: wave/heart/dance/cheer/clap/laugh/sit или anim://id
Meltiew.engine.vsync / max_fps / scale / fsr / msaa / fxaa / lod / physics_fps / soft_shadows — твики движка, только с флагом AdvancedFeatures
Meltiew.engine.detect(fn) — авто-подбор настроек под железо: fn({tier, adapter, cpu, ram_gb, rec})
Meltiew.players.list(fn) — кто сейчас в комнате; Meltiew.me — ты
Meltiew.sound.play("assets/zvuk.ogg") — звук из папки мода
task.wait / spawn / defer / delay — планировщик как в Roblox

Ресурс-паки

pack.json подменяет встроенные звуки, текстуры плейсов и курсор:

{
  "sounds":   { "jump": "assets/jump.ogg", "coin": "assets/coin.wav" },
  "textures": { "asset://12": "assets/текстура.png" },
  "cursor":   "assets/курсор.png"
}
  • Ключи sounds — имена встроенных звуков: pop, coin, jump, land, hurt, boing, join, click...
  • Ключи textures — точный ref текстуры (asset://<id>).
  • Конфликт двух модов: побеждает включённый позже (по алфавиту id), в лог пишется warning.

Свой каталог: публикуем моды

Каталог — это файл mods.json. Он может лежать в репозитории на GitHub или на любом своём сайте — пользователь добавит каталог прямой ссылкой на mods.json. Внутри — имя, описание и список модов:

{
  "name": "Мои моды",
  "description": "Каталог модов nekitMM",
  "mods": [
    {
      "id": "advice",
      "name": "Совет дня",
      "version": "1.0.0",
      "description": "кратко",
      "file": "advice.zip",
      "sha256": "необязательно: certutil -hashfile advice.zip SHA256"
    }
  ]
}
  • name и description — показываются на карточке каталога.
  • file — путь к zip рядом с mods.json или абсолютный URL на любой сайт.
  1. Собери мод в zip — кнопка ZIP на карточке мода. Внутри архива: index.json и main.luau (в корне или в одной папке).
  2. Размести каталог: репозиторий на GitHub (user/repo) или свой сайт с прямой ссылкой на mods.json.
  3. Пользователи: «Моды → Каталог → Добавить репозиторий» → вставляют user/repo или ссылку → «Установить».
  1. Запушь. Пользователи: «Моды → Каталог → Добавить репозиторий» → user/repo → «Установить».
  2. Обновления: перезалей zip, подними version в mods.json — кнопка станет «Обновить».
  3. Попади во встроенный каталог: список живёт в константе BUILTIN_CATALOGS в client/scripts/autoload/mods.gd.

GitHub-каталоги читаются с raw.githubusercontent.com/<user>/<repo>/HEAD/mods.json — ветка не важна. Свои каталоги можно хостить где угодно: подойдёт прямая ссылка на mods.json.
